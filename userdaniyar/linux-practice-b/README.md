# Linux Practice B

## 1. Создание пользователя и группы

Создана группа `developers` и пользователь `student2`.

Пользователь `student2` добавлен в группу `developers`.

Проверка:

```bash
groups student2
```

## 2. Настройка каталога

Создан каталог `/srv/shared`.

Владелец каталога: `root`.

Группа каталога: `developers`.

Права доступа: `775` (`rwxrwxr-x`).

Команды:

```bash
sudo mkdir -p /srv/shared
sudo chown root:developers /srv/shared
sudo chmod 775 /srv/shared
```

Участники группы `developers` могут создавать и удалять файлы в каталоге. Остальные пользователи могут просматривать содержимое, но не могут изменять каталог.

## 3. Проверка прав доступа

Файл `student2_test.txt` создан от имени пользователя `student2`.

Команда:

```bash
sudo -u student2 touch /srv/shared/student2_test.txt
```

Возможность удаления файла основным пользователем зависит от его прав на каталог `/srv/shared`.

Удаление файла определяется прежде всего правами на родительский каталог. Если у пользователя нет права записи в каталог, он не сможет удалить файл обычным способом.

## 4. Отличие su от sudo

`su` позволяет переключиться на другого пользователя. Если имя пользователя не указано, обычно выполняется переключение на `root`.

`sudo` позволяет выполнить отдельную команду с повышенными привилегиями или от имени другого пользователя, если это разрешено настройками системы.

Основное отличие: `su` обычно открывает оболочку другого пользователя, а `sudo` чаще используется для выполнения отдельных команд с нужными правами.

## 5. Почему вход под root в Ubuntu по умолчанию заблокирован

В Ubuntu учётная запись `root` по умолчанию не имеет установленного пароля для обычного прямого входа. Вместо постоянной работы под `root` используется `sudo`.

Это помогает снизить риск случайного изменения системных файлов и ограничить выполнение административных команд.
