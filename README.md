<WritingBlock id="58314" variant="document"># Практическая работа №1
Тема
Управление пользователями, группами, правами доступа и настройками Bash в Ubuntu.
1. Создание пользователей и группы
Была создана группа developers и дополнительный пользователь student2. Пользователь student2 добавлен в группу developers.
2. Настройка общего каталога
Создан каталог /srv/shared. Его владелец — root, группа-владелец — developers.
Для настройки прав использована команда chmod 2775 /srv/shared.
Владелец и участники группы имеют права чтения, записи и входа в каталог. Остальные пользователи имеют права чтения и входа, но не могут создавать или удалять файлы. Бит setgid обеспечивает наследование группой новых файлов и каталогов группы developers.
3. Проверка прав доступа
От имени пользователя student2 был создан файл student2_file.txt в каталоге /srv/shared.
При попытке удалить этот файл от имени основного пользователя, не входящего в группу developers, система выдала Permission denied.
Причина: основной пользователь не имеет права записи в родительский каталог /srv/shared. Для удаления файла необходимо право записи и входа в родительский каталог.
4. Разница между su и sudo
Команда su позволяет переключиться на другого пользователя, например su - student2, и запустить оболочку от его имени. Обычно для этого требуется пароль целевого пользователя.
Команда sudo позволяет выполнить отдельную команду с правами другого пользователя, обычно root, если текущему пользователю разрешено это делать. Как правило, вводится пароль текущего пользователя.
Главное отличие: su обычно используется для переключения пользователя, а sudo — для выполнения отдельных команд с повышенными правами.
5. Почему вход под root по умолчанию заблокирован в Ubuntu
В Ubuntu учётная запись root обычно изначально не имеет установленного рабочего пароля для прямого входа. Административные команды выполняются через sudo.
Это уменьшает риск случайного изменения системных файлов и позволяет контролировать административные действия. Также пользователю не нужно постоянно работать с максимальными привилегиями.
6. Настройка Bash
В файл ~/.bashrc добавлены два alias:
- ll='ls -lah'
- cshared='cd /srv/shared'
Добавлена переменная окружения STUDENT_NAME.
Работа настроек проверена в новой сессии Bash.
